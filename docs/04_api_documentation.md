# API Documentation

All protected routes require a JWT Bearer token in the `Authorization` header.

## Auth Routes
*   `POST /auth/register` - Create a new user. Requires `email` and `password`.
*   `POST /auth/login` - Authenticate and receive a JWT token. Requires `username` (email) and `password` as form data.

## Workout Routes (Protected)
*   `GET /workouts/` - Get a list of all workouts for the logged-in user.
*   `POST /workouts/` - Log a new workout. Accepts `workout_type`, `exercise_name`, and a flexible `details` JSON object.
*   `DELETE /workouts/{id}` - Delete a specific workout by ID.

## AI Routes (Protected)
*   `GET /ai/insights` - Fetches the last 10 workouts and returns a personalized insight generated by Google Gemini.
