
## Agile Scrum Methodology

This project was developed iteratively using Agile Scrum methodology. As a solo developer, I acted as the Product Owner, Scrum Master, and Developer.

### Sprint 1: Foundation & Auth (Week 1)
*   **Goal:** Set up the cloud database, FastAPI backend, and secure JWT authentication.
*   **Deliverables:** Neon DB connection, SQLAlchemy models, `/register` and `/login` endpoints.

### Sprint 2: Core Workouts & AI (Week 2)
*   **Goal:** Build the CRUD API for workouts and integrate Google Gemini AI.
*   **Deliverables:** Dynamic JSON workout schemas, Gemini API integration, `/workouts` and `/ai/insights` endpoints.

### Sprint 3: Frontend & UI/UX (Week 3)
*   **Goal:** Build a responsive React frontend with a premium dark mode UI.
*   **Deliverables:** Login page, responsive Dashboard, Recharts integration, 365-day heatmap.

### Sprint 4: Deployment & Polish (Week 4)
*   **Goal:** Deploy to production and write documentation.
*   **Deliverables:** Vercel deployment, Render deployment, CORS configuration, this documentation folder.
